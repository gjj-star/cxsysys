# 个人中心接口适配与验证

完成日期：2026-11-13。接口依据为同目录的 OpenAPI 快照及[适配核查记录](personal-center-review-2026-11-13.md)。本次保留现有页面布局、主题和导航，接入截图中未划线的个人中心接口及头像上传、文件获取。

## 已完成行为

| 页面/操作 | 实现 |
| --- | --- |
| 我的、个人信息 | 共用用户状态，进入页面刷新 `GET user`；姓名、手机、用户名、企业、角色和账号状态显示接口数据，空字段显示横线。 |
| 本人头像 | 复用拍照/相册选择；上传带 `type=avatar`，上传成功后刷新资料；清除时发送 `{"avatar_url":null}`。姓名等其他字段保持只读。 |
| 头像读取 | 仅向配置的业务域名及文件路径发送当前用户 token；禁用跳转和图片缓存，切换账号后重新创建图片状态，失败显示默认图标。 |
| 企业信息 | 原有名称、ID、电话、地址四行绑定真实数据；成员卡片改为姓名/用户名、角色的只读列表，支持游标分页和失败重试。成员使用默认头像。 |
| 修改密码 | 保留三个输入框，校验长度、UTF-8 字节数、两次一致及新旧不同；防止重复提交，失败保留输入；普通账号成功后清除会话并返回登录，超级管理员按后端例外保留会话。 |
| 退出登录 | 确认后先发注销请求，再清除本地凭据、用户缓存和相关页面状态；401 也可退出，断网/超时会说明服务端注销未确认。 |

资料页将原“认证状态”改为“账号状态”，避免把账号启用误显示为实名认证。帮助/反馈、设置和关于页沿用现状。

## 必要的共享逻辑调整

- 沿用 Retrofit、StateFlow、SharedPreferences 和既有错误提示方式，没有新增 Repository 或依赖注入框架。
- 通过 token 与会话版本隔离异步请求，阻止退出或切换账号后的旧响应覆盖当前账户，也阻止旧写请求误用新账户凭据。
- 保留通用上传的默认参数，其他业务上传无需修改调用；头像上传成功已由后端保存，不重复调用修改资料。
- 业务 HTTP 日志改为 BASIC，避免登录响应 token、密码和修改密码正文进入日志。
- Debug 网络配置允许回环地址，供离线联调使用；正式接口地址和 release 网络配置没有因此更改。

## 后台模拟器验证

使用独立 API 37 x86_64 模拟器、`-no-window` 和仅监听 `127.0.0.1` 的本地模拟 API；测试包通过 Gradle 参数临时关闭超级管理员注入并覆盖 API 地址。未操作桌面 UI 或用户原有模拟器。验证完成后关闭临时模拟器和本地服务。

以下流程均通过：

1. 密码登录后，“我的”显示模拟用户、企业及带鉴权的本人头像。
2. 个人信息页显示各真实绑定字段及“账号状态：正常”，保持原有卡片布局。
3. 清除头像发送显式 null，页面同步显示默认图标。
4. 系统相册选择图片，上传包含 `file` 和 `type=avatar`；服务端收到图片后刷新用户信息，无重复修改头像请求。
5. 企业信息显示空字段横线；成员首次 10 条，下一页携带 `lastid=1010`，共显示 12 条后不再显示加载更多。
6. 旧密码错误时显示服务端错误，三个输入保留；正确改密后普通用户会话失效并返回登录。
7. 使用新密码重新登录后，确认退出发送 `POST user/logout`，服务端会话失效，页面回到登录状态。

本机联调记录位于忽略的 `app/build/reports/personal-center/`：页面截图、布局快照、脱敏请求记录及临时模拟服务。记录不保存 token 或密码值。页面截图已逐张查看。

## 验证边界

此前线上只读核查已确认用户、企业、成员和本人头像接口可用。本次写操作在本地模拟服务验证，没有修改线上真实账号的头像、密码或登录会话；仍需专门普通测试账号完成线上写接口验收。

用户当前启用了 `enableSuperToken=true`，重新启动应用会再次注入开发身份。验收普通账号的改密后重新登录、退出后重启行为时，需要用 `-PenableSuperToken=false` 构建或自行关闭此开关。拍照设备交互、真机和打印硬件未在本轮验证。
